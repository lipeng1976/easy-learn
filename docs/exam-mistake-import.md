# 试卷错题 MD 导入（ima → 错题本）

> 落地日期：2026-11-15。场景由虫子提出：**考完的试卷**，错题信息不是作业、
> 也不是每日打卡，只能在 ima 里手工整理，希望 App 能读回来并针对性练。

## 1. 边界（先看这个）

| | 说明 |
|---|---|
| 输入 | ima `教学资料/试卷错题/` 下的**手工整理 MD**，一试卷一份 |
| 输出 | `review_mistake`，`source_type='ima_exam'`、`source_ref=<media id>`、`state='pending'` |
| 出题 | 导入即用现有「组卷/重做卷」（`review_service.dart` 优先用 `questionBody`）与「举一反三」；**AI 网关零改动** |
| 不做什么 | 不解析 PDF、不读 ima 的「错题档案」镜像、不导入原卷照片、不改计划侧出题范围 |

### 为什么单独建目录

App 每次交卷会把错题**推送**成 `错题档案-<学科>-<日期>.md`（`buildMistakesMarkdown`）。
2026-11-15 时那个文件夹已有 **84 份镜像**，数学那份含 83 条旧错题。若导入列表直接
列「错题档案」，家长误选一份就会把几十条旧错题重复灌回错题本，**且不报错**。
所以输入独立放在 `教学资料/试卷错题/`，与推送镜像物理隔离。

### 双保险：格式闸

- 手工试卷 MD 的分节写 `## 知识点：相反数`；
- App 自动镜像写 `## 相反数`（知识点名直接当标题）；
- 解析器 `parseExamMistakes` **只认带「知识点：」前缀的分节**，镜像解析结果为 0 条，
  导入端点响亮 400。
- 末尾「知识点总览 / 本次核对中判定为作答正确…（备查） / 复习建议」等 `##` 段一律跳过。

判据 `test/exam-mistake-import.test.js` 第 4、11 条专门盯这道闸（还原后恰好 2 条变红）。

## 2. MD 格式模板（复制即可）

```markdown
# 错题档案 · 数学（2026年下学期七年级期中检测卷）

- 导出于：2026-11-15
- 学科：数学
- 来源试卷：2026年下学期七年级期中检测数学试卷（共4页，25题，满分120分）
- 本次归档错题数：2 条；涉及知识点：2 个

## 知识点总览

|知识点|条目数|累计错误次数|
|---|---|---|
|相反数|1|1|

## 知识点：相反数

### 七上期中检测卷 · 第1题 · 相反数

- 学科：数学
- 题干：2026 的相反数是（ ）
A. 2026 　 B. -2026 　 C. $\frac{1}{2026}$ 　 D. $-\frac{1}{2026}$
- 错因：把「相反数」与「倒数」混淆，学生勾选了 C。
- 正确答案：B
- 来源作业：2026年下学期七年级期中检测卷 第1题（第1页）
- 状态：待复习；错误次数：1；最近做错：2026-11-15

## 本次核对中判定为作答正确、不纳入错题的内容（备查）
- 选择题第3-10题：均正确。

## 复习建议
- 概念辨析强化：相反数、倒数、绝对值做对比卡。
```

规则：

1. 每道错题放在一个 `## 知识点：<知识点>` 段里的 `### <标题>` 下；`###` 标题建议含
   `第N题` 或 `第N题(小问)`，用于生成 `question_no`。
2. 字段行用 `- 字段：值`；**题干 / 错因允许跨行**（选项、多行说明会续接到同一字段）。
3. 必填只有 `- 题干：`；没有题干的段落**跳过**，不会存一道空白题。
4. 支持字段：`学科`、`题干`、`错因`、`正确答案`、`来源作业`、`状态`、
   `学生答案`、`解题过程`。文件头的 `- 学科：` / `- 来源试卷：` 作兜底。
5. LaTeX 原样保留（`$...$`），客户端错题详情 / 重做卷用 `MathText` 渲染。
6. `状态` 行里的 `错误次数：N` 会写 `wrong_count`；时间统一用数据库 `now()`，
   **不采信 MD 里的设备时间**（本机时钟偏一天会把统计带偏）。
7. 年级 / 学期取**学生当前档案**（`app_user.grade/term`），不解析文件名或路径。

### 给 ima 的生成提示词

> 请把我上传的这份考试试卷整理成「错题档案 MD」，只保留我做错的题，按下面格式输出。
> 文件首行写 `# 错题档案 · <学科>（<试卷名>）`，接着写 `- 学科：`、`- 来源试卷：`。
> 每道错题单独一节 `## 知识点：<知识点名>`，下面用 `### <试卷简称> · 第N题 · <知识点>`
> 起头，再写 `- 题干：`（完整题干与选项，公式用 LaTeX）、`- 错因：`、
> `- 正确答案：`、`- 来源作业：`、`- 状态：待复习；错误次数：1；最近做错：<日期>`。
> 最后可以写「本次核对中判定为作答正确、不纳入错题的内容（备查）」和「复习建议」，
> 这两段不会被 App 当错题。**不要**把「知识点总览」写成 `## <知识点名>` 的形式，
> 也不要省略 `知识点：` 前缀。

## 3. 落库映射

| MD | `review_mistake` 列 |
|---|---|
| `### 标题` | `title` |
| `## 知识点：X` | `knowledge_point` |
| `- 题干：` | `question_body` |
| `- 正确答案：` | `answer_key` |
| `- 错因：` | `wrong_reason` |
| `- 来源作业：` / 文件头 `- 来源试卷：` | `source_homework_title` |
| `### …第23题(1)` | `question_no`（`23(1)`） |
| `- 状态：…错误次数：N` | `wrong_count` |
| 学生当前档案 | `grade` / `term` |
| ima media id | `source_ref` |
| 固定值 | `source_type='ima_exam'`、`state='pending'`、`image_count=0` |

⚠️ `homework_id` **留空**。`028` 迁移的注释写过：把非作业 id 塞进去，作业详情页
会去 `homework` 表查一条不存在的行，而且不报错。

## 4. 端点与幂等

| 端点 | 作用 |
|---|---|
| `GET /data/exam/mistakes/files?studentId=` | 列 `教学资料/试卷错题/` 下 MD + 每份已导入条数；ima 不可用时恒 2xx `connected:false` |
| `POST /data/exam/mistakes/import` | 下载 → 解析 → 按 `(student_id, source_type, source_ref)` 删旧行 → 写入 |
| `POST /data/exam/mistakes/revoke` | 撤销某份 MD 导入的错题（幂等，没导入过返回 `removed:0`） |

- 重复导入**同一 mediaId** 不翻倍。
- 在 ima 里**重新上传**同名 MD 会生成新 mediaId ⇒ 算另一份（与教材换版同一现象）。
  这时用页面上的「撤销」删掉旧那份导入的错题，再导入新的。
- 删旧行的 SQL 必须同时带 `student_id` 与 `source_type='ima_exam'`。
  少了后者会把作业 / 打卡 / 手录的错题一起删掉，且页面不报错。

客户端入口：家长端「复习」页 **①「可以做的一件事」区（标题正下方、首屏）** →
「从 ima 导入试卷错题」。导入的题会进 ③「按学科看错题」里对应的学科色块。

⚠️ 11-15 真机反馈「看不到这个功能」：入口原来挂在 `ListView` 最底部的
「错题清单」标题下，前面压着进度卡 / 薄弱知识点 / 复习资料 / 作业提交记录，
首屏根本滚不到 —— `ListView` 是懒构建，视口外的 widget 连树都不进。
**低频但重要的操作必须紧跟标题**，不能按「语义上属于错题」就塞到末尾。
位置由 `test/exam_mistake_import_test.dart` 的两条判据盯着（源码顺序 + 默认视口坐标），
真还原证伪：挪回底部恰好 2 红 / 8 绿。

没开通 ima 时按钮整块隐藏，不弹红条、不抛异常。

### 3.1 客户端来源枚举（11-15 晚补齐）

`ima_exam` 一度在客户端被**静默读成「手工录入」**：`MistakeSource` 里没有这个值，
`mistakeSourceOf` 一路兜底到 `manual`，界面照样画得出，只是那 4 条试卷错题的来源永远显示错。

| 层 | 取值 |
|---|---|
| 服务端 / 历史数据 | `source_type = 'ima_exam'`（下划线） |
| 本地 sqflite | `sourceType = 'imaExam'`（Dart 枚举名） |
| 上行（`overwrite` / 新增） | `mistakeSourceWire()` → `'ima_exam'` |

🔴 **上行不能直接用 `name`**。编辑一道试卷错题走 `/data/review/mistakes/overwrite`，
如果发的是 `imaExam`，服务端那行就变成下划线之外的写法，而导入 / 撤销的幂等
一律按 `source_type='ima_exam'` 匹配 —— 家长只是改了个错因，重新导入同一份试卷
就会**多出一整套题**，且不报错。单点在 `lib/models/review_model.dart` 的
`mistakeSourceWire()`；`test/mistake_source_wire_test.dart` 有一条源码级判据
专门盯「上行有没有被改回 `sourceType.name`」。

`source_ref` 不在 `MISTAKE_SPEC` 里，`overwrite` 不会清空它，改错题不影响导入幂等。

详情页汇总条只在真有试卷导入时露一行「其中 N 道来自考试卷导入（ima 整理）」；
恒为 0 时不写「0 道」，否则看着像导入失败。

## 5. 已知限制

- 不导入原卷图片（MD 里也没有）。实践题读图那类题目目前只有文字描述，
  「举一反三」按知识点 + 题干要点出变式题，不保证贴原题图形。
- 「举一反三」不看 `question_body`（网关 `handlers.js:912` 明确「没有原题照片，按知识点出」）。
  真正原样练这几道题走「组卷 / 重做卷」，它优先用题干文字。
- 计划侧（今天练什么）仍按教材 / 家长指定范围出题，**不因导入错题改变范围**；
  导入的错题只通过 `collectCheckinSeeds` 补 `wrongCount` / 错因权重。
- ima 开放接口没有删除 / 移动文件能力，目录与文件搬动要在 ima 客户端里做。
