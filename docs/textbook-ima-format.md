# 教材怎么放进 ima · 骨架 MD + 提示词

> 配套 `subject-textbook-design.md`。产出物是**章节骨架**，不是教材全文，也不是题目。
> 2026-11-12 · 使用前把 `【教材名】` 换成实际书名。

---

## 一、先说结论：PDF 还是 MD

| 教材类型 | 放进 ima 的东西 | 原因 |
|---|---|---|
| 英语词表 | 教材 PDF **+** 词表 MD（`教学资料/Wordlist`） | PDF 给 ima 读，MD 给 App 导入；词表是纯文本表格，转 MD 几乎无损 |
| 英语故事书 | 故事书 MD（`教学资料/English`） | 同上，已跑通 96 课 |
| 语文课文 | 整本 MD 可用 | 内容本身就是文字 |
| **数学 / 物理 / 化学 / 生物 / 地理 / 历史 / 政治 / 英语教材题** | **只放「骨架 MD」**，PDF 留在 ima 当引用源 | 见下 |

> ⚠️ **第三方工具把 PDF 转成 MD，产出的「全文 MD」不是骨架，不能直接导入。**
> 转换器的 `##` 是排版标题（课文名 / `Section A` / `Conversation` / 词汇表），
> 不是教材目录；而 App 约定「每个 `##` = 一节」。11-13 现场实测：一本英语全文 MD
> 导进来认出 27 节，标题是 `Keep Tidy!` / `SECTION` / `Look and share` /
> `Section A, 2c and 2d` / `Vocabulary A–Z`，**没有一个 Unit、0 条 `考点：`**，
> 书名还变成了封面文字「英语ENGLISH」。全文 MD 必须**二次提炼**成骨架（第三节）。

### 为什么不整本转 MD

转 MD 会丢的东西，恰好是理科题目的**前提条件**：

| 教材里有什么 | 转 MD 后 | 后果 |
|---|---|---|
| 公式 | LaTeX 能写，但模型转写常错（`\frac` 被吃成 `rac`、`\f` `\t` 变成控制字符） | 式子算出来是错的 |
| 图（几何图、函数图、电路图、地图、实验装置） | 丢。base64 内嵌可以把体积撑到几十 MB，且版面错位 | 题目缺条件，孩子做不出来 |
| 表格（跨页、合并单元格） | 结构散 | 数据题读不出对应关系 |
| 页码 / 版式 | 丢 | 无影响 |
| 纯文字（时间线、定义、结论） | 不丢 | 无影响 |

**更关键的是：出题不需要正文。** 出题要的是「这一节考什么」。把正文喂给模型有三个坏处：
模型抄原题、prompt 几 MB、范围失控（自己往外扩）。骨架里的「考点清单」已经足够定位。

所以 App **从不解析 PDF**，也**从不读教材正文**。边界是：ima 负责把书变成结构，App 只吃结构。

## 二、骨架长什么样

```markdown
# 人教版七年级上册 数学

## 第1章 有理数 | p1
考点：正数、负数、数轴、相反数、绝对值

## 第2章 整式的加减 | p23
考点：单项式、多项式、同类项、合并同类项、去括号
```

三行一节。解析器认这些：

- 一行 `# 书名`（**可省**，省了就用文件名当书名）
- 每节 `## 标题 | p页码`（`|` 可省；全角 `｜` 也认）
- 紧跟着一行 `考点：a、b、c`（半角 `:` 也认）—— **这一行可以省**
- 其它行一律忽略（分隔线、说明文字不会导致导入失败）
- `###` 不算新的一节（模型多打一个 `#` 不会多出半节）

**章号不由标题决定**，而是「文档里出现的顺序」。因为教材写法各不相同（`第1章` / `Unit 1` / `一、` / `Chapter One`），
解析必然覆盖不全 —— 而覆盖不全时**不报错**，只是章号乱掉。顺序是最稳的。

### 「考点：」行省略时，章节标题就是知识点（11-12）

历史、政治这类骨架经常只有 `## 第7课 百家争鸣`，一行考点都没写。旧实现把这种书
**整本判成「没配考点」**，退回错题本；而历史这种还没学过的科目本来就没有错题 ——
于是家长点一次报一次「错题本还是空的」，书明明配好了却从没生效过。

现在一节至少产出一个点：**写了考点拆考点，没写就用章节标题**。
「第7课 百家争鸣」对模型是完整语境，出题质量不比自编的考点词差。

> 所以骨架 MD 可以只写目录。想考得更准再补 `考点：` 行 —— 有考点时标题不参与出题。

## 三、给 ima 的提示词（整段复制）

````text
请只依据本知识库里的教材《【教材名】》，生成一份供「伴学 APP」导入的教材骨架 Markdown。

【输出要求】
只输出一个 ```markdown 代码块，代码块前后不要任何解释、总结、例题或附加说明。
代码块内最后一行用 > 开头写统计（这行会被导入器忽略）：
> 节数：N ｜ 建议文件名：book-XXX.md

【格式样例，严格照抄结构】
# 人教版七年级上册 数学

## 第1章 有理数 | p1
考点：正数、负数、数轴、相反数、绝对值

## 第2章 整式的加减 | p23
考点：单项式、多项式、同类项、合并同类项、去括号

【规则】
1. 每节一个二级标题，写成「## 章节标题 | p页码」。页码取该节起始页；查不到就省略 `| p...`。
2. 标题下面紧跟一行「考点：」，用中文顿号「、」分隔 3~15 个考点。
3. 考点必须是**知识点名词**（如「合并同类项」「速度公式」），不要写题目、例句、定义、公式推导。
4. 节的数量与教材目录一致，按目录顺序排列，不要按字母或页码重排。
5. 只抽到「节」这一级，不要再往下拆小节；一节课本里有几个小节就合成一条，考点合并。
6. 不要输出教材正文、例题、定理原文、图片、表格。
7. 不要联网、不要用通用知识补课本里没有的章节。
8. 数学/物理/化学的考点请写成概念名，不要写符号或公式（例如写「一元一次方程」，不要写 ax+b=0）。

【生成前逐条自检】
- 每一节都有 `##` 标题，且下一行是「考点：」。
- 考点之间全部用「、」分隔，没有换行、没有编号、没有逗号。
- 节数与教材目录对得上，没有整章漏抽，也没有把一章拆成十几条。
- 代码块里没有正文段落、没有例题、没有表格。
- 统计行在代码块内最后一行，以 > 开头。
````

### 英语专用版（教材题考语法 / 时态 / 句型，不考单词）

英语教材的「单元」常被 PDF 转换器拍平，而且**单词题归词表 MD 管**。用这一版，
别把课文对话和单词条目喂进来：

````text
请只依据本知识库里的英语教材《【教材名】》（PDF 或全文 MD），生成一份供「伴学 APP」导入的教材骨架 Markdown。

【输出要求】只输出一个 ```markdown 代码块，代码块前后不要解释、例题、单词表或总结。

【格式样例，严格照抄结构】
# 人教版七年级上册 英语

## Unit 1 My name's Gina | p1
考点：一般现在时、be 动词、人称代词、形容词性物主代词

## Unit 2 This is my sister | p7
考点：指示代词、名词复数、一般现在时

【规则】
1. 二级标题按教材目录的**单元**写：`## Unit N <单元标题> | p页码`。
   起始单元写 `## Starter Unit N <标题>`。页码查不到就省略 `| p...`。
2. 每个单元紧跟一行 `考点：`，3~8 个**语法 / 时态 / 句型**概念，用中文顿号「、」分隔。
3. 考点**不写单词**：单词题由另一份词表 MD（`教学资料/Wordlist/`）负责，
   两套解析器互不替代，教材骨架里也没有词条 / 音标 / 释义。
4. 不要输出课文对话、例句、听力原文、练习编号（Section A / 2c / Conversation）、
   词汇表、图片、表格。
5. 单元数量与目录一致，按目录顺序，不按页码或字母重排；只到「单元」这一级，
   不再往下拆 Section。
6. 不要联网、不要用通用语法知识补课本里没有的单元。

【生成前逐条自检】
- 每条 `##` 都是 `Unit N` / `Starter Unit N`，没有把课文标题或栏目名当单元。
- 每个单元下一行都是 `考点：`，且全是语法概念、没有一个单词条目。
- 代码块里没有正文段落、对话、例题、表格。
````

## 四、放在哪

| 项 | 值 |
|---|---|
| 位置 | 学生自己的 ima KB（`伴学-<姓名>-<学号前6位>`）里的 `教学资料/教材/<学科>/` |
| 学科目录名 | 必须与 App 的科目名一致：`语文` `数学` `英语` `物理` `化学` `生物` `历史` `地理` `政治` `其他` |
| 文件名 | **任意可读名**即可（年级学期在导入弹窗里选，不靠文件名）。例：`book-人教版七上.md`、`02_数学_七年级上册_人教版.md` |
| 类型 | Markdown（`media_type = 7`） |
| 体积 | ≤ 2 MB（骨架一般 5~40 KB） |

操作顺序：把骨架文本存成 `.md` → 在 ima 的 `教学资料/教材/数学` 里上传 → App「学科范围 → 教材 → 从 ima 导入」。

> 为什么按学科分一层目录：配置页只列**本科目**的书。靠文件名前缀（`数学-xxx.md`）猜学科，
> 家长改个名字就失效，而且失效是静默的 —— 数学书会出现在语文列表里，或者干脆不出现。

### ⚠️ 目录只到**学科**这一层，不要按年级建子文件夹

服务端拼的是 `教学资料/教材/<学科>/`（`textbook.js` 的 `TEXTBOOK_FOLDER_PATH`），
**只下探一层、不递归、不解析年级**。建成 `教材/七上/数学/` 会让 `findTextbookFolder`
找不到 `数学`，返回 `folder_missing`，可导入列表空 —— 书在 ima 里却看不见。

年级学期是**书本身的属性**：导入弹窗里显式选（预填学生档案年级），落 `subject_book.grade/term`
（迁移 `029`）。ima 目录只是人类浏览层，系统契约不认路径。所以 `book-七上.md` / `book-七下.md`
都放在同一个 `教材/数学/` 里，年级写进文件名和首行书名即可。

> ⚠️ **弹窗里的年级写「初一 / 初二 / 初三」**，与学生档案、错题本归档同一套词
> （11-13 起统一到 `kGradeOptions`）。文件名 / 书名里的「七年级上册」只是给人看的，
> 系统不解析。若之前导入时选过「七年级」这类别名，客户端会自动归一成「初一」，
> **不用重新导入、也不用改数据库**；重新导入同一本时落库值会自然收敛成规范词。

> 首行建议写 `# 人教版七年级上册 数学`。骨架里没有 `# 书名` 行时，
> 书名会兜底成去掉 `.md` 的文件名（带 `02_` 这类前缀也照显示），不影响出题。

### 英语：教材骨架与词表是**两份**，不要合并

英语要建两份 MD，各放各的目录、走各的解析器：

| 资料 | 位置 | 内容 | 用途 |
|---|---|---|---|
| 教材骨架 | `教学资料/教材/英语/` | 章节 + `考点：一般现在时、名词复数`（**语法 / 时态 / 句型**） | AI 出教材题（`subject_scope` 按章节推进） |
| 词表 | `教学资料/Wordlist/` | `## Unit N` + `word｜音标｜中文释义` | 本地单词选择题（`word_scope`） |

英语骨架样例（考点写语法概念，不写单词）：

```markdown
# 人教版七年级上册 英语

## Unit 1 My name's Gina | p1
考点：一般现在时、be 动词、人称代词、形容词性物主代词

## Unit 2 This is my sister | p7
考点：指示代词、名词复数、一般现在时
```

⚠️ **不要指望从教材骨架里拆出单词**：解析器只把 `考点：` 拆成知识点词组
（`subject_unit.summary`），没有词条、音标、中文释义，本地单词题出不来。
反过来词表 MD 也没有语法考点。两者互不替代，且教材 PDF 本来就同时含有这两类信息 ——
两本资料是同一本教材的两种投影，不是重复劳动。

**出题形态已真跑验证**（11-13，本机网关）：`subject=英语`、知识点 `一般现在时 /
现在进行时 / 名词复数` → 3 题全保留、`rejected=[]`，中文题干 + 英文选项、
答案字母 `B/T/B`，`knowledge` 原样回抄。`normalizeQuestions` 只校验结构与字母，不看语言。

## 五、导入之后发生什么

1. 服务端下载这份 md → 解析成「节 + 考点」→ 写进 `subject_book` / `subject_unit`；
2. 家长在配置页选书、选「从第几节开始」、「每天几节」，保存进 `subject_scope`；
3. 每次出题：服务端取当前这几节的考点 → 当知识点 → 交给模型；
4. 出题成功后，游标自动往后推「每天几节」；
5. 教材只在**导入那一刻**碰 ima。之后断网、ima 掉线、家长删了文件，出题都照常 —— 因为它只读 PG。

## 六、常见问题

**Q：教材换了版本（比如人教版改版）怎么办？**
A：同名文件重新上传后，在配置页再导入一次。会覆盖章节但**保留书 id**，家长原来选的起始节还在（若超出新节数，下拉会自动退回第 1 节）。

**Q：用第三方工具把教材 PDF 转成 MD，导进去分不清 Unit 几，是 App 没读到吗？**
A：不是丢数据，是**喂错了格式**。全文 MD 里的 `##` 是排版标题（课文名 / `Section` /
`Conversation` / 词汇表），不是教材目录；App 约定「每个 `##` = 一节」且**刻意不解析章号**
（节号 = 出现顺序），于是把正文碎片当成节。先在那份全文 MD 里搜 `Unit`：
若是 `#` / `###` / 纯文本，App 确实读不到（只认 `##`）；若压根没有，就是转换时丢了目录。
**两种情况解法一样：把全文 MD 二次提炼成骨架再导入**（第三节英语专用版）。
全文 MD 别留在 `教学资料/教材/英语/`，挪到别处，否则导入列表里两份 `.md` 容易点错。
换骨架后重新导入同一个 ima 文件会 `delete from subject_unit` 再写新节、保留书 id，
家长不用手动清那 27 节。

**Q：ima 换了新骨架，旧的那本还留在 App 里，怎么删？**
A：分两层，别混为一谈：

- **App 里的导入记录**：进「学科范围 → 教材 → 删除已导入」，选书、二次确认即可。
  删的是 `subject_book` + 它的全部章节，同时清掉指向它的范围设置。若删的是
  当前正在用的那本，页面会同步清掉本地配置，随后保存不会把已删 id 写回去。
- **ima 里的原文件**：ima 开放接口**没有删除文件的能力**（只能创建 / 列举 / 读取），
  所以「删不掉」是接口限制，得在 ima 客户端里手动删除，或把它移出
  `教学资料/教材/<学科>/`。留着不影响出题（教材已经落库到 PG），但会一直出现在
  「从 ima 导入」的候选列表里 —— 别再点它，否则又导进一本 27 节全文。

⚠️ 重新上传同一个文件名会生成**新的 media id**：`import` 只按 media id 幂等，
所以旧记录不会自动被覆盖，App 里会变成两本书，要按上面的办法删掉旧的那本。

**Q：一本书能不能拆成两本？**
A：能。按学期拆（`book-七上.md` / `book-七下.md`）更好用 —— 「每天推一节」跨学期会一直往前。

**Q：没有教材能不能出题？**
A：能。不选教材就用「手填范围」（`subject_scope.points`），或者发起时临时勾知识点。
教材是**更好的范围**，不是唯一的范围。

**Q：没教材、也没填范围呢？**
A：这时**不会出题**，也不会编题去凑一次打卡 —— 那会让孩子在完全没学过的东西上被扣分。
点色块会直接进配置页（并说明「还没有出题范围」），选一本教材就能开始。
⚠️ **不会拿错题本兜底**：错题本属于「复习」那条线（见 `doc/review-vs-plan.md`），
拿它出计划题会让两条线的来源混在一起，而界面上看不出来。
历史、政治这类「还没学过所以不可能有错题」的科目，走的就是先说这一步。
