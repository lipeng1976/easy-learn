# 第 0 章 打开应用

## 0.1 三种打开方式

| 方式                 | 现在能用吗      | 怎么做                                                                                      |
| ------------------ | ---------- | ---------------------------------------------------------------------------------------- |
| **网页版**（手机或电脑的浏览器） | ✅ **能用**   | 浏览器打开 **`https://banxue.app.workbuddy.host/`**。不用装任何东西。第一次打开要下载运行库（约 5MB，几秒钟），之后会走缓存、快很多 |
| **安卓手机**           | ✅ **能用**   | 安装我们提供的安装包（`.apk`）。如果系统提示「未知来源」「不允许安装」，在手机设置里允许一次再装                                      |
| **苹果手机 / iPad**    | ⏳ **还不能用** | 应用本身已经适配 iPhone 和 iPad，但还没在 Mac 上打包、也还没上 App Store。**苹果设备请先用网页版**                        |

> ✅ **换设备不用重做一遍**：数据存在**账号**下，不在手机里。  
> 网页版、安卓版用的是**同一份代码** —— 登录同一个账号，作业、错题、积分、心愿一条不少。
>
> ⚠️ **网页版是 2026-09-26 刚上线的**。功能与手机版完全一致（同一份代码、同一套后端），  
> 但**建议你第一次先试一遍「注册 → 登录」**：这一步通了，后面就都通了。

## 0.2 第一次用：注册

点登录页的「**注册新账号**」，进入「**创建伴学账号**」：

1. **选身份** —— 「学生」或「家长」（默认选中「学生」）。⚠️ **选错了看到的就是完全不同的界面**：学生端是「作业 / 运动 / 复习 / 计划 / 心愿」，家长端是「首页 / 计划 / 复习 / 心愿 / 积分」；
2. **手机号** —— 占位提示「请输入11位手机号」，最多 11 位；
3. **密码** —— 占位提示「6-16位数字和字母组合」；
4. **再输一遍**确认密码；
5. 勾选《用户协议》；
6. 点「**注册并登录**」。

**注册成功即登录**，直接进对应角色的首页，不用再登一遍。

> ✅ **注册不需要短信验证码** —— 现在就能注册真实账号。
>
> **常见的失败提示**：
>
> - 「**注册失败** / 两次输入的密码不一致」→ 重新输一遍；
> - 「**注册失败** / 暂时无法连接认证服务，请稍后重试」→ 检查网络后再试。

## 0.3 登录

打开是登录页，标题「**伴学APP**」，副标题「**家庭亲子学习监督平台**」。

| 步骤         | 说明                                             |
| ---------- | ---------------------------------------------- |
| ① 选身份      | 「学生」或「家长」。⚠️ 身份是登录的一部分：**手机号 + 密码 + 身份**三者都要对上 |
| ② 填手机号、密码  | 手机号会一直记着                                       |
| ③ 「记住密码」   | **勾了才存密码**。不勾的话下次得重新输                          |
| ④ 勾《用户协议》  | **没勾，登录按钮是灰的** —— 这是有意的，免得点下去才发现没同意            |
| ⑤ 点「手机号登录」 |                                                |

**几个细节**：

- 登录页会显示「**上次使用：手机号密码**」之类的历史。首次使用**什么都不显示**（刻意不默认写一种，否则新用户会看到一句不存在的历史）。
- 登录不成功时提示「**手机号、密码或身份不正确**」。⚠️ **它不告诉你是哪一项不对** —— 这是**故意的**（否则别人可以拿它试探「这个手机号注册过没有」）。真忘了密码请看第 6 章。

## 0.4 登录页上灰着的入口（先说明，免得以为是坏了）

| 入口               | 状态                                             |
| ---------------- | ---------------------------------------------- |
| 「**验证码登录（未开通）**」 | ⛔ 点进去是禁用状态。**不是坏了，是短信服务还没接入**（第 6 章）           |
| 「**微信授权登录**」     | ⛔ **还没接入**（第 6 章）。点它会提示「**微信登录尚未接入，请使用手机号登录**」 |
| 「忘记密码 / 找回密码」    | ⛔ 依赖短信，同样还没开通                                  |

**为什么留着入口而不是藏起来**：把「功能没做好」和「服务没接入」分开说。  
看到「尚未接入」就不会反复重试；看到「发送失败」才会一直点。

## 1.1 交作业（Tab 1）

```
作业 Tab → 加附件（照片一次最多 9 张；另可加音频 3 个、视频 1 个）
              ↓
        （可选）拍照识别导入文字（一次最多 4 张）
              ↓
           提交 →「提交成功」
              ↓
        等待批改（AI 自动批改）
              ↓
        错题自动进入「错题库」→ 在复习 Tab 能看到
```

**具体操作**：

1. 在「作业」Tab 点提交，弹出提交面板；
2. 加附件 —— **照片一次最多 9 张**；音频最多 3 个（单个 ≤20MB）、视频最多 1 个（≤50MB）；
3. 想省事就点 **拍照识别导入**：把照片里的字认出来、填成作业条目，  
   **一次最多 4 张**（上限不是为了技术，是为了**你核对得完** —— 页数越多越容易直接点保存）；
4. 核对一下认出来的条目（可以改、可以删），再提交。

**会看到的提示**：

| 什么时候     | 会看到                                  |
| -------- | ------------------------------------ |
| 提交成功     | 「**提交成功**」                           |
| 提交失败     | 「**提交失败**」+ 具体原因                     |
| 上次拍的照片还在 | 「**已找回照片**」/「上次拍摄的照片还在，已经放进待提交列表」    |
| 相册读不出来   | 「**选择失败**」/「无法读取图片：…」                |
| 网页版存储不够  | 「**当前浏览器存储空间不足，照片本次可以查看，刷新页面后会丢失。**」 |

> ⚠️ **认不出作业内容时不会瞎编**：如果照片太糊、认不清楚，系统**不会**给你造几条任务出来 ——  
> 因为那几条会被当成「今天真的要做的作业」。一条都认不出来时会如实告诉你，这时**重拍一张**。

> 💡 **「把握偏低」不等于「认不出来」**（2026-09-29 起）：手抄清单本来就写得潦草，  
> 模型对整个版式的把握自评分会偏低。这时系统**照样把认出的条目摆进核对表单**  
> （照片就在表单上方，可以放大对照），只在顶部提醒你**逐条核一遍**，科目认错了也能直接改。  
> 在这之前，这种情况会被整份当成「没能认出作业内容」丢掉 —— 白拍一场，重拍多少次都一样。

> 💡 **板书上的题号连写会被读成列举**（2026-09-29 起）：学生常把几个题号连写成一串  
> （`1.2.37`），照抄原样看不出它到底含几道题。系统会读成 **`1、2、3、7`**，  
> 也就是第 1、2、3、7 题，放进表单时就是这个样子。  
> ⚠️ 一个例外：**含 0 的两位题号不拆**（`1.2.10` 读成「第 1、2、10 题」），  
> 因为题号里没有「第 0 题」。读错了直接在输入框里改，不影响别的条目。

**批改完之后**：错题会自动进入错题库，去「复习」Tab 就能看到它们等你复习。

💡 **每条错题都留了四样东西**（2026-10-21 起）：原题题干、**卷面题号**
（如「第 20 题 (4)」）、学生当时**写出来的解题过程**、以及批改时算出的标准答案。
题号让家长能翻到作业本上的那一题；解题过程让讲解能直接指出「你就是这一步错的」，
而不是只说一句「答案不对」。
⚠️ 题号和解题过程都可能没有：作业本来就没编号、那道题是选择题没有过程 —— 这时就空着，
不会编一个出来。

💡 **批改结果上的「错题 N 道」是可以点的**（2026-10-20 起）：点它直接进  
「**本次作业的错题**」，只列这一次作业产生的题，按时间最新在前。  
之前那个数字是一段纯文字，想找刚错的题只能去复习 Tab 里翻历次作业。

**录错了 / 录重了怎么办**：

**① 只是科目或内容认错了 —— 直接改**（2026-09-29 起）：

1. 在「作业」Tab 找到那份作业，点卡片右上角的 **⋮**；
2. 选「**修改科目或内容**」；
3. 科目用下拉选，内容直接改；顺手也能改「要不要批改」；
4. 点「**保存修改**」。

> 💡 只有你**真正动过**的那几项会被写回去，没碰过的字段**一个字都不动**。  
> 这件事在你有两台设备、或者家长那边也开着的时候有意义：它不会拿你手上  
> 这份「旧的值」去覆盖掉对方刚做的改动。
>
> ⚠️ 「预计耗时」在这一步**改不了**（修改面板里没有这个输入框，核对识别结果  
> 时才有）。原因是它和别的字段走的不是同一条通道 —— 与其给你一个**改了却存不上**  
> 的框，不如先不给。

**② 整份都不需要了 —— 删掉**：

1. 在「作业」Tab 找到那份作业，点卡片右上角的 **⋮**；
2. 选「**删除这份作业**」；
3. 确认框里会写明**连带删掉什么**，看清楚再点。

> ⚠️ **删除不可逆，而且连带删掉的不只是这一条作业**：
>
> - 这份作业的**照片**；
> - 它的**批改结果**；
> - 它带出来的**错题**（连同那些错题的作答、讲解与复习记录）；
> - **家长端那条记录也会消失**；
> - 但**已经拿到的积分不会收回**。
>
> 所以：**识别认错了字、或者同一份作业被识别了两遍**，趁早删 —— 越晚删，它带出来的错题越多。
>
> ⚠️ **正在批改的作业删不了**：菜单里那一项是灰的，写着「正在批改，等批改结束再删」。  
> 这是故意的 —— 批改要把结果写回这份作业，中途删掉会留下一个说不清的中间状态。
>
> ⚠️ **家长端没有删除入口**：家长端对作业一直只能看。要删得由孩子在学生端删。

> ⚠️ **真实手写体的已知边界**：认字整体是准的，但**最潦草的一档会把字认成另一个「通顺的词」**  
> （比如「静夜思」认成「静在恩」），而且它**自报的把握还挺高**。  
> 所以：**认出来的文字不能替代对着原图核对一眼**。

### 专注计时：看看这一份到底写了多久

作业卡片上有一行 **「专注计时」**，点它就进入一屏只有时间的界面。

```
点「专注计时」→ 立刻开始计时（屏幕常亮）
      ↓
  中途要上厕所 / 被叫走 → 点暂停（时间冻结）
      ↓
  回来点继续 → 接着原来的数字走
      ↓
点「结束并保存」→ 这份作业多一行「实际用时 12 分 34 秒」
```

几条规则先说清，免得以为是坏了：

- **只有计时中的时间才算**。暂停的时间、切到别的 App 的时间、锁屏的时间都**不计入**；
- 切出去 / 锁屏会**自动暂停**，回来点一下继续就行（界面会写「你刚才离开了应用」）；
- 屏幕上那个大数字是**本次**；底部小字才是「此前已记录 + 本次一共多少」；
- **同时只能给一份作业计时**。开始第二份时会问一句，先把上一份结束掉再开始；
- 中途按返回会问「继续计时 / 暂停并返回」，不会悄悄把这段专注结束掉。

> ⚠️ 计时本身**不产生分数、不排名、不比较**。它只回答一个问题：这一份，你花了多久。

#### 计时屏下方的「知识点提示」

时间下面那块卡片，是**这个科目**错题本里的一句话提示，例如：

> 「一元二次方程」你已经错了 3 次：先用一句话说出它的定义，说不出来就先翻书。

- 它是从**当前科目**的错题归纳的，换一份语文作业就不会出现数学的提示；
- 每隔十几秒换一条，也可以点「换一条」自己翻；
- 联网时由模型归纳「这个知识点本身最该记住的一句」；离线时显示的是  
  **自检问句**（如实写出错了几次），不会编一个公式；
- 这个科目还没有错题时，这里会写「做完作业批改后会出现提示」。

#### 连续学 40 分钟会提醒休息

右上角那个 **「40 分钟」** 就是提醒阈值，点它可以改成 25 / 40 / 50 / 60 分钟，  
或者**不提醒**（存这台手机，换设备要重设）。

到点后会同时发生三件事：**整屏从冷色变暖色**、**念一句**「站起来走两步，看看远处」、  
**弹出提醒卡**。卡上有两个选择：

- **「好，去休息」**：计时暂停并保存，连续时长清零。回来点继续即可；
- **「再学 10 分钟」**：这次提醒收回，10 分钟后再来一次。

「连续」是认真的：**暂停超过 3 分钟**才算休息过，回来从头算；上个厕所两分钟不算。  
不这么定的话，按一下暂停再继续就能把提醒绕过去。

#### 给「计划」计时，以及临时打卡

同一个闹钟不只能给作业用：

- **计划页**上，每个生效中的计划卡片也有一行「专注计时」——  
  「每天阅读 20 分钟」这种条目，点了就是给**这个计划**记时间；
- 计划页最上面还有一个 **「临时打卡 · 记一段时间」**：今天忽然想读会儿书、  
  想下楼跑两圈，点它 → 选一个标签（阅读 / 运动 / 练字 / 背诵 / 错题复习 / 其它）  
  → 同一个闹钟就开起来了。

三种目标记法上的区别（界面底部小字会写清楚记到哪儿）：

| 在给什么计时 | 记到哪                                   |
| ------ | ------------------------------------- |
| 某份作业   | 这份作业的「实际用时」**+** 今天的投入                |
| 某个计划   | 只记**今天**在这个计划上的时间（计划是按天重复的，昨天读的不算进今天） |
| 临时打卡   | 只记今天，按标签汇总                            |

0 秒不记：进去看一眼就退出来，统计里不会出现「今天阅读 0 分钟」。

> ⚠️ 同时仍然**只允许一段计时**。在别处已经在计时时，会先问一句  
> 「要先结束它、再开始这一段吗」—— 选「结束并开始」的话，上一段会**先存好**再换。

## 1.2 复习闭环（Tab 3）—— 整个应用最完整的一条流程

⚠️ **这是步骤最多的一条，也是「纸和笔 + AI」这个特色最集中的地方。**  
它模拟的是真实学习场景：**在纸上做题，做完拍照回传。**

```
【第 1 步】复习 Tab「待复习」里的错题
              ↓ 组卷
【第 2 步】组卷页：选好题，生成一张卷子（可以导出 / 打印）
              ↓ 线下做卷（学生在纸上完成）
【第 3 步】回传页：逐题标记对错 → 录入卷面答案 → 拍照留档 → 提交批改
              ↓
【第 4 步】单卷报告：这一张卷的结果
              ↓ 累积
【第 5 步】周期报告：周报 / 月报
```

### 复习 Tab 长什么样

从上到下：

1. **统计条** —— 待复习 / 复习中 / 待批改 / 已掌握 四个数，下面是掌握率。  
   ⚠️ 自己点「标记掌握」的不计入掌握率；
2. **一行筛选** —— 左边是**学期**，右边是**科目**，点开才是选择器；
3. **三段切换** —— **待复习 / 复习资料 / 已掌握**；
4. **错题卡** —— 标题、一行来源信息（科目 · 知识点 · 来自哪次作业 · **日期**）、  
   错因（最多两行，全文点进去看）。

**点卡片任意位置就能进详情**（不用先找「讲解」按钮）；卡片右下角的 **⋮** 里  
是「标记掌握 / 编辑 / 删除」这三个低频动作。

**如果一道错题都没有**，会看到「**当前筛选下没有待复习的错题**」/「完成作业并提交检查后，错题会自动进入错题库」。  
⚠️ 看不到错题时先确认筛选：学期看的是「本学期」，科目看的是不是只选了某一科。

### 组卷页要注意什么

- **卷子是一份快照**：组卷那一刻，题目就被冻结进这张卷子里了。之后错题库再怎么变，**这张卷子上的题不会变** —— 这样批改时才对得上号。
- 顶部有一条进度链：`组卷 → 导出 → 回传 → 批改`，一眼看出走到哪一步。
- **答案默认收起来**（免得忍不住直接看答案）。
- ⚠️ **导出失败或你中途取消，卷子不会被标成「已导出」** —— 免得出现「显示已导出、其实没导」。

### 取走卷子：三种方式，拿到的都是 PDF

点「生成错题资料」（或资料卡上的导出）会弹出「取走这份卷子」，三条路：

| 方式              | 会发生什么                                     |
| --------------- | ----------------------------------------- |
| **打印 / 另存 PDF** | 调起**系统打印服务**，选打印机；没有打印机时，在里面选「另存为 PDF」    |
| **保存 PDF 文件**   | 弹**系统「另存为」**，你自己选存到哪个文件夹（下载 / 文档 / U 盘都行） |
| **转发到微信**       | 调起**系统分享面板**，选微信即可把 PDF 发出去               |

⚠️ 2026-10-21 之前这里导出的是 HTML 文件，存在 App 的私有目录里 ——  
**普通用户在手机上根本找不到那个目录**，所以只能看到一句「已保存到：/data/user/0/…」。  
现在一律生成 PDF，并且把「存到哪」交给你自己选。

- 卷子上带 **参考答案页**（另起一页），可以在面板里关掉「附带参考答案」，只印题目；
- **卷面印的是原题**：完整的题干（含选项、分步提问），学生拿着纸就知道要做哪道题。  
  ⚠️ 2026-10-21 之前这里只有一句「重新独立完成这道题」，**没有题目本身** ——  
  现在改成印 `questionBody`（AI 批改时识别出的题干）。
- **原题带照片的，照片会一起印上去**（每题最多两张）。几何图、表格、  
  手写的原题这些用文字表达不了，没有图就没法做；
- 题目里的公式会转成能印的写法（`$x>20$` → `x>20`，`\frac{1}{2}` → `1/2`），  
  不会出现美元符号和反斜杠。
- ⚠️ **已经生成的卷子是快照**，不会因为这次修正而自动补上原题；  
  想看到原题请**重新组一份卷子**。

### 回传页的四步

做完卷子回来录结果：

1. **逐题标记对错** —— 哪些对了、哪些错了；
2. **录入卷面答案** —— 把答案敲进去；
3. **拍照留档** —— 拍张照存证（家长端能回看）；
4. **提交批改**。

> 💡 **「自评」和「判定」是两回事**：只标对错不写答案，**不算掌握证据** ——  
> 参与给分和掌握率的是「写了答案并被判定」的那条路。

## 1.3 错题详情与「举一反三」

点开一道错题，里面有三个页签：**讲解 / 举一反三 / 过程**。

### 「讲解」页签

AI 讲这道题为什么错、怎么想。

**点「朗读讲解」能听**（只有手机版有，网页版没有朗读）：

- 公式会读成人话：`\frac{1}{2}` 念作「2 分之 1」，`x^2` 念作「x 的平方」；
- **句与句之间会停一下**，不会一口气念到底；
- 念到一半想停，按钮会变成「正在朗读，点这里停止」；离开这一页会自动停。
- **声音不满意，去「个人信息设置 → 朗读设置」**（资料页往下翻，在「账号与安全」上面），  
  换引擎、换音色、调语速，右上角有「试听」。  
  **设一次就记住**，所有讲解都用这个声音，下次打开 App 也还是它 —— 不用每次朗读前再挑。

> **声音不是 App 自带的语音包**，它来自你手机系统的「文字转语音」引擎。  
> App 会自动挑本机**质量最高、且不需要联网**的中文音色。  
> 挑不到也不会不出声 —— 会用系统默认那个继续念，朗读设置顶部会说一句。
>
> 如果还是觉得生硬，装一个更好的语音包就好：  
> **设置 → 系统 → 语言和输入法 → 文字转语音输出** → 选一个引擎  
> （Google 语音服务或手机自带）→ 进它的设置 →「安装语音数据」→  
> 下载**中文（中国大陆）**&#x7684;**高质量**包。装完回 App 重新进讲解页即生效。  
> 换手机、换引擎后声音会跟着变，属正常。

> ⚠️ **鸿蒙手机（应用通过卓易通安装）大概率听不了朗读。**  
> 鸿蒙 NEXT 不再带安卓的语音合成服务，卓易通也没有实现它 —— 这不是装语音包能解决的  
> （缺的是服务，不是数据）。朗读设置里会显示一行**诊断**：引擎几个、初始化返回什么码，  
> 你能直接看到是「一个都没起来」还是「只是没有中文包」。
>
> **只有「一个都没起来」才是真的没救**，那时讲解照常显示，只是没有声音。  
> 如果只是「没有中文包」，App 会用**系统默认的声音**继续念（朗读设置顶部会有提示），  
> 题照样听得见 —— 这种情况装个中文语音包就能变好听。
>
> **讲解朗读**仍然只用手机自己的语音引擎：讲解文本一个字节都不出手机，也不用为朗读付月费。  
> 代价就是系统层面没有语音合成服务的设备听不到讲解。
> （英语阅读的**伴读**是另一条路，手机直连微软朗读接口、不通才退回服务器，见后面「英语阅读」那一节。）

### 「画一张理解图」—— 听不明白就看图

朗读按钮下面还有一张卡片：**画一张理解图**。点一下，等几秒（通常 2~6 秒），
这道题会画成一张图摆在讲解上面。

- 适合**数轴、图形面积、行程、函数**这类"关系摆出来才看得懂"的题。
- **纯计算题不会画**（有理数运算、解方程、幂运算……）。这时卡片会说
  「这道题不画图」并给一句理由 —— 这不是出错，是它判断画了也没用，
  硬画一张反而会挤掉下面的讲解。
- 题干里写着「**下图**」「**如图**」但当初没拍原题照片时，**它不会画**。
  没见过原图就画，只能编一个像的，你会一眼看出"这不是我那题"。
  想要这张图，编辑这道题时补上原题照片即可。
- 一张图只生成一次，看完在内存里留着；**关掉 App 就没了**，再点一次会重新画。

> 图是**按坐标画出来的**，不是 AI 直接"画"的图片。所以图上标的每条边长、每个角度，
> 与画出来的线条长度是一致的 —— 不存在"标着 a 的边看着像 b"这种图。

### 「举一反三」页签 —— 做题

系统会出几道**变式题**（换个数、换个问法，考同一个知识点）。你可以：

- **直接打字回答**；
- **拍照作答** —— 拍下你手写的解答，AI 认出你写了什么、填进输入框，**你能看见、也能改**，确认没问题再提交。

> ✅ **拍照只是「输入方式」，不是「判定方式」**：拍完照，AI 把你写的字认出来填到框里，  
> 之后走的是和打字**完全相同**的那条判定。不会出现「同一份答案，打字提交判错、拍照提交判对」。
>
> ⚠️ **认不出来时不会瞎填**：照片太糊的话，系统**不会**往输入框里塞东西，只会提示你。  
> 理由很直接 —— 填一段它编出来的字，等于替你写了一个你从没写过的答案。

### ⚠️ 「换一组」会清掉已填的答案

点「**换一组**」换一批题时会**先弹一个确认框**，因为「**换一组会清掉已填的答案**」。  
换掉之后你填的那些**没有副本可以恢复** —— 不小心点一下，半小时的输入就没了，所以这里必须拦一下。

### 「标记掌握」

学生自己点「标记掌握」时会看到：「**已标记为掌握（自评不计入掌握率）**」。  
**自己点不算数** —— 否则点几下就能把错题清空，掌握率就没意义了（第 4 章规则一）。

## 1.5 学习计划（Tab 4）

**顺序**：家长下发计划 → 学生看到 → **接受或拒绝** → 每天打卡。

计划有五种状态：

| 状态 | 什么意思 |
|---|---|
| `待学生确认` | 家长刚发下来，等你点头 |
| `生效中` | 你接受了，正在执行 |
| `已拒绝` | 你拒绝了 |
| `家长已撤回` | 家长自己收回去了 |
| `已完成` | 做完了 |

下方还有一块「历史记录」。

> ⚠️ **历史记录旁边有一句必须留意的说明**：「**历史按当前计划推算，与当时可能不同**」。
> 意思很直白：它**不是当时的存档**，而是**用现在的规则倒推出来的**。
> 家长后来改了计划内容，历史记录也会跟着变 —— **别拿它当证据用。**
>
> ⚠️ **撤销打卡不会把记录删掉**：原记录打上撤销标记，再补一笔负数，**一分不多、一分不少**。
> 所以别指望反复开关打卡能刷分。

### 概念打卡（计划页顶部那张卡）

家长按学科 / 知识点 / 题量 / 难度出一组短题，孩子在**计划页顶部**那张卡点进去作答。

**规则（2026-10-29 起）**：

- **出的题不限当天**。家长昨天出的、孩子没做的，今天打开还在 —— 一直等到做完为止。
- 打卡页分两区：**未完成**（全部，早出的在前）、**已完成**（最近做的在前，一页 10 份，底部「加载更多」翻页）。
- 入口卡的「待完成 N 份」是**跨天累计**，跟点进去看到的是同一个数。
- 家长每点一次「出新的打卡题」就是**一份新试卷**：旧的题与成绩一律保留，同一天想再出一套也行。
- 交完卷分数立刻出（本机判），再同步到云端；同步失败会标「未同步」并给「重试」，**分数不会因此消失**。

> 入口卡三种状态：`还没有题`（灰，谁都没出过）、`待完成 N 份`（绿，还有要做）、`已全部完成`（灰）。
> 一份都没有时**不会**亮绿标催你 —— 那是提醒系统在催，其实是你自己还没出题。

### 英文阅读（计划页第二张卡）

家长从 ima 知识库的「教学资料/English」里选一本 md 书，布置给孩子；孩子每次读一篇、打卡一次，
**整本书读完这份任务才算结束**。

**规则**：

- **任务挂在「书」上，不挂在「某一天」上。** 没有「今天必须读第几篇」这回事 ——
  今天没读，明天打开还是那一份，进度原样不动。系统里根本没有「顺延」这段逻辑，
  因为它不需要。
- 读书顺序是**锁死**的：只能读下一篇。跳着点会被拒绝并告诉孩子「下一篇是第 N 篇」。
- 同一篇重复点不会多算一次（断网重试、两台设备同时点都一样）。
- 读到最后一篇的同一次请求里，任务自动变「已读完」—— 不用等下次打开才变。
- 一本书同时只有**一份**进行中的任务。读完可以再布置同一本（重读），进度从 0 开始，旧记录保留。
- 家长可以随时取消任务；已读的篇数不会丢，重新布置同一本书时进度接着算。

**家长怎么开始**：

1. 计划页 →「英文阅读」卡 →「布置阅读任务」；
2. 「从 ima 导入」里选一本 md →「导入」（一本 96 课约 1~2 秒，切好的课会存进库）；
3. 「我的书库」里点「布置」；
4. 孩子计划页立刻出现这张卡，显示 `x/96 篇`。

> **想再导入第二本书**：把 md 放进 ima 的「教学资料/English」，回到这一页点
> 标题右侧的**刷新**。列表只在进页面时读一次，不刷新就看不到新放进去的书 ——
> 曾经没有任何刷新入口，导入第一本之后整块只剩几行「已导入」，看起来像功能没了。
> 导入成功后也会自动再读一次，所以「先导一本试试、再补第二本」不会卡住。

> 书的要求：md 里必须按 `Lesson 1` / `Lesson 2` … 分课（标题的 `#` 层级无所谓），
> 每课最好有「美文赏析 / 词汇详解 / 参考阅读」三段 —— 有就分别显示，没有就整课当正文。
> 一本书里一节课都识别不出来时**会拒绝导入并说明原因**，不会存一本空书进去。

**孩子怎么读**：

点卡片 → 读英文正文 → 生词和中文译文默认收起（先看英文，看不懂再点开）→
读完后点底部「我读完了，打卡」→ 进度 +1，按钮变「读下一篇」。

> 正文里**这一课的生词用粗体蓝色标出来**，一眼能看到该留意哪些词。
>
> 生词表给的是原形，文中常常是 `spent` / `stopped` / `studies` 这类变形，所以匹配时
> 先做词形还原（复数、过去式、进行时、比较级 + 一张不规则动词表）。96 课 344 个生词
> 实测能标出 97.7%。剩下标不出的有两类：**原书词汇表列了、正文里确实没这个词**
> （如 `lesson`、`own`），以及要靠派生词才对得上的（`honesty`↔`honest`）——
> 派生不做，因为 `hard`↔`hardly` 这种意思变了，硬标反而误导。

**看打卡记录（学生 / 家长都一样）**：

计划页的阅读卡里直接写着「今天已读 N 篇」，并把今天读的那几篇列出来（第几篇、标题、几点）；
点右边的「全部记录」进记录页，按天分组显示每一次打卡。

> 记录页顶部可以按「今天 / 近 7 天 / 近 30 天 / 全部」查，也可以「选日期」查任意一段。
> 默认落在「近 30 天」，**标题栏能看见当前选的是哪一段** —— 不是一段藏起来的过滤。
>
> 进度条只回答「读到第几篇」，所以打卡记录是**另外查出来的**（`reading_log` 里
> 存着每次打卡的本地日和课号）。这也意味着：读完整本书、或者家长把任务取消了，
> 已经打过的卡都还在，点「全部记录」随时能翻。

**伴读（听一遍）**：底部「我读完了，打卡」**左边**的「伴读」按钮。点了几秒后开始念，
准备音频那几秒按钮显示「准备中…」，开始念之后变「停止」，再点就停。
切到下一篇、离开页面会自动停。

**一听就知道声音从哪儿来（11-08 起）**：**男声 = 本机，女声 = 云端兜底**。

| 听到的 | 走的哪条路 | 要不要联网 / 花不花钱 |
|---|---|---|
| 男声（Guy） | 手机里已经存好的音频 | **完全不联网**，断网也能听 |
| 男声（Guy） | 手机自己直连微软朗读接口 | 要联网，但**不经自家服务器、不花 AI 额度** |
| 女声（芊悦 Cherry） | 直连失败 → 自家网关 → 百炼 Qwen | 要联网，走云端合成 |

伴读按钮上方在朗读时会多一行小字，直接写明「男声 · 本机缓存 / 手机直连」或
「女声 · 云端 Qwen 兜底」，不用靠耳朵分辨。两条路**音色不同是刻意的**，
不是 bug；换音色时本地音频缓存也跟着换键，所以不会出现「选了新音色却放旧录音」。
代价：云端兜底那次不留离线副本（直连成功时照常存，断网可听不受影响）。

**语速**：伴读按钮上方有「语速 正常 / 慢速」两个小胶囊，给刚开始学英语的孩子选**慢速**。
慢速是正常速度的 **0.8 倍、音高不变**（不会变成慢吞吞的低音），**设一次就记住**，
下次进来还是这一档；**念到一半切也立刻变**，不用停下来重听，也不会重新合成一遍。
已经存到手机里的课文断网时同样能慢着听。

> 和「个人信息设置 → 朗读设置」里的语速**不是一回事**：那边调的是手机系统 TTS 念
> 讲题的速度，这边调的是英文伴读的播放倍率，两边各存各的，互不影响。

> 只念英文正文，**不念**收起的中文译文 —— 收起的部分却被念出来，孩子会莫名听到一串中文。
>
> **优先顺序**：先查手机本地音频 → 再手机**自己直连**微软朗读接口 → 直连不通
> （网络拦掉、接口改版）才自动退回服务器合成。11-08 起退回时会**换成女声**，
> 这样家长一听就知道这次走到了云端，不用翻日志。
> 两条都拿不到音频时才会提示「这一篇的语音还没存到本机，需要联网加载一次」。
>
> **第一次听完会自动存一份在手机里**，之后这一篇**断网也能听**，也不必再合成。
> 存储有上限（约 200MB，超了按最久没听的先删），正常够存几十篇课文。
>
> **多久能出声**：整篇一次合成的话，最长那一课（约 4800 字符）要等十几秒才有声音。
> 现在按段落切块，**第一块合成好就开始念**（实测约 2 秒），后面的块边念边合成；
> 中途网络断了会停并提示，下次再点会**接着没合成完的地方补**，不用从头来。
>
> 为什么不能直接用手机自己的语音引擎：鸿蒙 NEXT（应用通过卓易通安装）里没有安卓的
> 语音合成服务，系统层面就念不出声 —— 这不是设置问题。
> 网页版/电脑版按不了，会提示「请在手机上使用」。

## 1.6 心愿（Tab 5）—— 赚积分、兑心愿

```
许愿 → 家长确认这个心愿（并定价：值多少积分）
         ↓
   孩子努力赚积分
         ↓
   点「确认完成」→ 点「申请兑换」   ← ⚠️ 这时候一分都不扣
         ↓
   家长点「同意兑换」              ← ⚠️ 扣分就发生在这一刻
```

> 🔴 **最容易误解的一条**：**申请兑换时不扣分，家长确认时才扣。**
> 这不是 bug，是**刻意设计的** —— 不可逆的损失不该由孩子单方面触发。
> 孩子点了申请、家长还没批，这时**可以撤回申请**，积分一分不动。
>
> 家长拒绝时会看到：「**这次「××」的兑换申请没有被同意，积分没有扣除。**」
> （家长写了理由的话，理由也会显示出来。）**拒绝不是封禁，你随时可以再申请。**

> ✅ **兑了就结束了**：家长点了「同意兑现」之后，这个心愿就算**实现**了 ——
> 卡片上写「已兑现 / 已闭环」，**不会再标「已逾期 N 天」**。
> （2026-10-31 修：此前兑现只记了时间、没记「家长已确认」，于是两端都一直红着「已逾期」，
> 家长端还找不到「确认已实现」的按钮，心愿永远关不掉。）

## 1.7 和家长聊天（右上角「伴学消息」）

- ⚠️ **这是和「已结伴的家长」聊天，不是和 AI 聊天**（页面标题就是「**伴学消息**」）；
- 前提是**已经和家长结伴**（第 3 章）。还没结伴时会看到：
  「**暂无已组队成员，组队成功后才能发送消息**」；

  写「今天 / 昨天 / 星期三 / 10月12日 / 2025年12月31日」。

## 1.8 消息通知（右上角铃铛）

作业提交、批改完成、计划打卡、心愿申请这些事件，服务端会写一条通知，打开这个页面就能看到。

- **点一条通知**：先标已读，再跳到能处理它的那一屏（作业 → 作业页、计划 → 计划页、
  心愿 → 心愿页）。报告类通知（每日点评 / 系统）点了只标已读。
- **「全部已读」**：右上角标题栏，一次把所有未读标掉；未读清零后按钮自己消失
  （留着它只会让人点一下、然后什么都没发生）。
  > 只改已读状态，不删任何通知，所以没有二次确认。
  > ⚠️ 只会标「**你**看得见的那部分」——单机上家长和学生共用一个库，
  > 不做这个区分就会顺手把孩子的专属通知也标掉，而孩子的红点会莫名其妙消失。
- ⚠️ **这一页只有 App 内提醒**：不打开 App 就收不到。要做离线推送（微信 / 短信）
  另有一套方案，见 `doc/parent-push-notification-todo.md`（**暂未实现**）。

## 2.4 心愿（Tab 4）—— 你要做三个决定

| 孩子做了什么 | 你要做什么 |
|---|---|
| 许了一个心愿 | **确认这个心愿**，并给它**定价**（值多少积分） |
| 点了「确认完成」 | 确认孩子真的做到了 |
| 点了「申请兑换」 | **同意或拒绝** ← 同意=扣分，拒绝=一分不动 |

- **定价可以反复改**：在孩子正式申请兑换之前，随时可以调整这个心愿值多少分
  （定价是家长的单方决定，不该被一次设定锁死）。
- **定价填 0 是合法的** —— 表示这个心愿**不消耗积分**，纯奖励。
- **「同意兑现」= 你认可它实现了**：这一笔同时打上「家长已确认」，卡片变成「已闭环」，
  日期不再催「已逾期」。⚠️ 此前只记了兑现时间、没记确认，卡片会一直红着「已逾期 N 天」
  （2026-10-31 修）。
- **拒绝时可以写理由**，孩子那边会看到。

> 💡 **定价的建议**：让孩子觉得「努力够得着」。定太高，孩子会直接放弃。

## 2.5 积分（Tab 5）—— 定规矩的地方

家长在这里看积分总览、**设定各项行为值多少分**（交作业多少分、打卡多少分……）。

分值设置表一共 9 项，其中两项是**每日练习**：

| 项 | 什么时候给分 |
|---|---|
| 每日练习完成 | 孩子交卷就记，**不看对错** |
| 每日练习全对 | 同一组题全对，**再**多记一笔 |

> 💡 这两项故意分开：合成一项的话，孩子错一道就一分没有，
> 「做完」这件事本身的激励就没了。想只奖励全对，把「完成」那项关掉即可。

> 💡 **明确 + 可达**：什么行为给多少分要写清楚；心愿的定价要让孩子觉得努力能得到。
>
> ⚠️ **分值设置是「按孩子独立」的** —— 给老大改了，老二的规则不变。
> ⚠️ **「额外奖励」按一次算一次**：你点两次就给两次的分，这是你的本意，系统不防。
>
> ✅ **余额是算出来的，不是存着的**：所以撤销打卡、改分值、兑心愿之后，
> 孩子看到的数字永远对得上账（每一笔变动都在流水里）。

## 2.8 计划页（Tab 2）：进行中与已结束

页面从上到下是：**今天练什么 → 新建计划 → 进行中的计划 → 已结束（一行小框）**。

  「没有进行中的计划」，而不是「还没有任何计划」。

# 第 3 章 家长与孩子怎么连起来

## 3.1 结伴：家长看不到孩子的数据？多半是没绑

```
家长输入孩子的手机号 → 创建邀请（待接受）
                          ↓
              孩子在自己的应用里接受
                          ↓
                  关系生效（active）
```

**家长端操作**：首页右上角 → **伴学结伴** → 填孩子手机号 → 「**发送结伴邀请**」。

🔴 **只有关系生效了，家长才看得到孩子的数据。** 没绑定之前，家长端是空的。

> ✅ **双方互见名字**：家长看到孩子的名字，孩子看到家长的名字。
> （曾经有个坑：结伴成功了、状态也对，但对方那一栏是空的 —— 因为接口只回了对方 id、没回名字。已修。）
>
> ⚠️ **对方还没同意时，两边都看不到对方的名字** —— 这是设计，不是缺口。
>
> **基数**：一个孩子**可以**被多位家长绑定（比如爸爸和妈妈），一位家长也**可以**绑多个孩子。

## 3.2 解除结伴（家长端，单方立即生效）

**在哪**：家长端 → **伴学结伴**页 → 已经结伴的那个孩子的卡片 → 右侧「**解除结伴**」按钮
（断开的链条图标）。⚠️ **只有家长能看到这个按钮**，学生端没有。

**点下去会弹一个确认框**，原话是：

> **解除与 ×× 的结伴？**
>
> 解除后你将看不到 TA 的作业、打卡与错题，也不能再和 TA 发消息。
>
> · 数据不会被删除，孩子的记录都还在他那边；
> · 如果以后重新结伴，你仍然可以看到全部历史，包括这段时间孩子自己记录的；
> · 孩子会收到一条「结伴已解除」的通知。

🔴 **三条必须记住的**：

| 问题 | 答案 |
|---|---|
| 孩子的数据会删掉吗？ | **不会。** 一条都不删 —— 解除只是「你暂时看不见」，不是「清空」 |
| 以后重新结伴，还能看到之前的吗？ | **能，而且是全部** —— 包括解除这段时间孩子自己记的作业、打卡、错题 |
| 孩子会知道吗？ | **会。** 孩子会收到一条「结伴已解除」的通知，**别指望这是悄悄断开** |

**生效范围**：**单方、立即**，不需要对方同意。

> ⚠️ **解除后家长端的表现应该是「那个孩子从各个页面都消失」**：首页、积分、复习都不再显示他。
> 如果你看到「结伴列表里已经解除了，但首页还看得到这个孩子」，那是**没刷新干净**，重新进一次即可。

## 3.3 一个家长怎么管多个孩子

家长端顶部有**孩子切换器**。

**切换之后，各个 Tab 的数据会跟着切到那个孩子** —— 这是家长端最常用的操作。

> 演示数据里「王老师」就同时带着两个孩子，用它登录可以演示这个场景。

# 第 4 章 四条最容易被误解的规则

这四条**必须讲清楚**，否则用户会当成 bug 来报。

## 规则一：错题要连续两轮通过才能「毕业」

一道**反复做错**的题，做对一次不够 —— 要**连续两轮**都通过，才能从错题库移出去。

**为什么**：做对一次可能是碰巧、可能是刚看过答案。连续两轮都过，才说明真会了。

⚠️ **自己点「标记掌握」不算数** —— 会明确告诉你「**已标记为掌握（自评不计入掌握率）**」。

## 规则二：心愿兑换**申请时不扣分**，家长确认才扣

孩子点了「申请兑换」，余额**没变** —— 这是**对的**，一分都不该扣。
扣分发生在**家长确认兑现**的那一刻。

## 规则三：解除结伴 ≠ 删除数据

家长解除结伴后：
- 孩子的数据**一条不删**；
- 重新结伴后**全部历史可见**，包括解除期间孩子自己记的；
- 孩子**会收到通知**。

详见 §3.2。

## 规则四：断网时**能看、不能写**

| 你想做的事 | 断网时 |
|---|---|
| **看**作业、错题、积分、计划 | ✅ 能看（读的是上次同步下来的缓存），会弹离线横幅 |
| **交**作业、**提**交复习、**打**卡、**申请兑换** | ❌ 写不进去，会提示「**这次修改没有保存到云端**」 |

> **为什么不做离线排队**：写操作一旦排队，就会出现「我明明交了、老师那边没有」这类两边说不清的状态。
> 宁可当场告诉你没成功，也好过事后扯皮。

# 第 5 章 遇到问题怎么办

## 5.1 两条横幅 —— 看到了不用慌

| 横幅 | 什么时候出现 | 什么意思 | 你该怎么办 |
|---|---|---|---|
| **离线数据横幅** | 断网了，或读的是本地缓存 | 你现在看到的是**上一次同步下来的内容**，不是最新的 | 连上网络会自己消失；**写操作会失败**（规则四） |
| **AI 降级横幅** | AI 判定 / 讲解用不了了 | 这次的判定**可能不是 AI 判的** | 可以继续用，但要知道结果的来源 |

> 横幅文案说的是**人话**：「**网络不可用，请检查网络后重试，界面显示的是上一次同步下来的内容。**」
> （早前版本会把网址、英文异常直接糊到界面上，已经修掉了 —— 那种句子用户没法据以行动。
> 2026-10-06 又扫了一遍：**聊天失败、照片保存失败**这些单独展示的地方也在漏网址和英文异常，
> 而且断网文案原先只说了「出事了」、没说「你该怎么办」，一并补上了。）

## 5.2 常见的失败提示

| 提示 | 什么情况 | 怎么办 |
|---|---|---|
| 「**手机号、密码或身份不正确**」 | 登录时三项有一项不对 | 核对身份是否选对；忘了密码看第 6 章 |
| 「**暂时无法连接认证服务，请稍后重试**」 | 登录 / 注册时连不上服务 | 检查网络，稍后重试 |
| 「**两次输入的密码不一致**」 | 注册时两次输入不同 | 重新输一遍 |
| 「**提交失败**」 | 作业没提交上去 | 检查网络，重试 |
| 「**微信登录尚未接入，请使用手机号登录**」 | 点了微信登录 | 就是还没接入，用手机号登录（第 6 章） |
| 「**短信服务尚未接入，暂时无法使用**」 | 点了短信相关功能 | 同上，不是坏了 |
| 「**这次修改没有保存到云端**」 | 断网时做了写操作 | 联网后重做一次 |
| 「**暂无已组队成员，组队成功后才能发送消息**」 | 还没和家长 / 孩子结伴就去聊天 | 先结伴（第 3 章） |
| 「**扣分失败：……**」 | 家长确认兑换时扣不动 | 看后面的原因（通常是余额变了），刷新重试 |

## 5.3 换设备 / 换账号 / 退出登录

- **换设备**：数据在**账号**下（不在手机里），登录同一个账号就能看到全部内容。
- **退出登录**：会清干净三样东西 —— 服务端会话、本地身份、**账号级缓存**（积分余额、通知列表）。
  > **所以换个人登录，不会看到上一个人的积分和通知**，这是刻意设计的。
- **断网也能退出登录**（服务端那一步失败也会继续登出）。

# 第 6 章 还没开通的两个功能

**这两个功能入口都在、但都还没接通**。提前说明，免得被当成故障。

## 6.1 微信登录 —— 还没接入

点登录页的「**微信授权登录**」会看到「**微信登录尚未接入，请使用手机号登录**」。

**为什么不能用**（三层，都不是「改个开关」能解决的）：

1. **代码层**：从没接过 —— 项目里没有任何微信 SDK 依赖；
2. **资质层**：微信开放平台需要**开发者认证**（**300 元/年**），未认证的账号用不了微信登录；
3. **域名层**（Web 版的关键）：微信要求授权回调地址是**已备案的公网域名**。
   而**网页版现在挂在分享链接的域名下，你无法给那个域名备案** ⇒ **网页版在结构上就接不了微信登录**。

> ✅ **但手机 App 版是另一回事**：移动应用绑的是**包名 + 签名**，**不依赖域名备案**。
> 所以「微信登录」这件事，等以后有了自己**已备案的域名**、或做 App 上架时再一起做更划算。
>
> **现在的替代方案**：手机号 + 密码注册（**不需要短信验证码**）—— 现在就能用。

## 6.2 短信验证码 / 找回密码 —— 只差一个服务商账号

验证码登录、找回密码、重置密码 **本期都不可用**。页面上的原话是：

> **短信服务尚未接入，暂时无法发送验证码。**
> **接入短信网关并开通后，本页会自动启用。**

- 个人信息页里「找回密码 / 修改密码」显示「**短信服务尚未接入，暂时无法使用**」；
- 从个人信息页点「找回密码」会**自动带上当前账号的手机号**，省得再敲一遍。

> **不是坏了，是还没接。** 代码结构与页面都已就位，接入短信服务商之后自动就能用。

## C.2 建议的演示顺序（约 12 分钟）

1. **登录**（1 分钟）：用学生账号登进去，指着底部 5 个 Tab 说一句「这是孩子的五个日常」；
2. **交作业**（2 分钟）：拍一张照片提交，说明「照片最多 9 张；朗读、背诵这类还能加一段录音或视频；也能拍照识别导入」；
3. **复习闭环**（4 分钟）：⚠️ **这一段是重点，慢慢讲** ——
   错题库 → 组卷 → 导出 / 打印 → 线下做卷 → 回传（标记对错 / 录答案 / 拍照）→ 报告；
4. **举一反三 + 拍照作答**（2 分钟）：点进一道错题，演示变式题与拍照作答；
5. **心愿 + 积分**（2 分钟）：讲清「申请不扣分、家长确认才扣」—— 这是设计亮点；
6. **切到家长端**（1 分钟）：切孩子、看概览、看「运行观察」，收尾。

## C.3 演示时的话术要点

- **强调「纸上做题、拍照回传」**：不是让所有题都在手机上做 —— 这更贴近真实学习习惯；
- **强调「家长确认才扣分」**：体现「不可逆的事不让孩子单方面决定」；
- **主动说「短信和微信还没开通」**：别让客户自己发现。主动说是「预留了入口、接入即启用」，反而是加分项；
- **主动说手写识别的边界**：认字准，但最潦草的字会认成别的通顺词 ——
  **所以界面上一直保留「对着原图核对」这一步**，而不是假装 100% 准。
