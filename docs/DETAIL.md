## 一、「静默失败」清单（全表）

失败不报错、只表现为「功能安静地不对」→ 每个现象都要有一条能看见它的判据。

| 现象 | 真相 |
|---|---|
| 刚提交看不到、重登就好 | 服务端返回那行被扔 → 占位 id（= id 问题招牌） |
| 浏览器全挂、后端无日志 | 预检被转给函数不接→405；App 不发 Origin⇒"手机好好的"(B24) |
| 保存报 405、客户端代码看着对 | `_send` 只 GET 走 get、其余全 post ⇒ `putJson` 实发 POST；判据要盯**报文动词** |
| 新接口回未知端点/404 | 服务端没部署；判据=新端点 404→401，不存在路径也须 404 |
| 点了没反应没提示 | ①Obx 没追踪"进行中"Rx(B21) ②`Get.toNamed<T>` 带类型参必抛，吞在手势回调(B40) ③子组件 build 不在外层 Obx 追踪区 |
| 判据一直绿其实没测 | ①字段名对不上空转绿 ②只断结果(B22) ③视口800×600(B23) ④文件没进 runner(B33) |
| health 报 vision:true 却不能用 | 纯文本模型静默丢 image_url⇒score:100 items:[]；health 只判 Key，换模型必跑真图 |
| 公式印成 `rac{2}{5}` | 模型少转义一层，`\f`/`\t` 被 JSON.parse 吃成 FF/tab⇒解前过 `latex-guard.js` |
| 资料「没有题目」过会有 | 占位 id 未采纳(R2) 或「还在取」落进 `isEmpty`⇒中间态要独立渲染分支 |
| 配好了教材、点出题却说「错题本还是空的」 | 骨架 MD 只有章节标题、没有「考点：」行 ⇒ 取点函数把整本判成没配（11-12，已修：标题兜底） |
| 范围里明明有这条，模型出的题全被丢 | 比较用的是严格字符串相等；模型改了空格（「第 7 课」→「第7课」）就判越界（11-12，已修：`knowledgeKey` 忽略空白并归一回原文） |
| 一个「点了才失败」的按钮 | 已配置但范围空（没教材、没手填、没错题）时仍可点 ⇒ 家长以为点错了。修法：本地判 `bookId \|\| points`，空则直接进配置页 |

## 二、判据纪律（展开）

- **"全绿"不构成判据**：每修复必须证伪 —— 还原后恰好那几条变红、反面仍绿；先确认红的是断言不是编译。
- **判据太弱/样本太少会把噪音读成结论**（B27）：只断科目⇒内容层两成错看不见；3 次样本称 87.5%→15 次实测 75.8%。
- **用户说「XX 不行」先查上游**：怪模型⇒查「答对了 App 怎么处置」；说「没功能」⇒查「走不走得到它」。
- **「造了数据」≠「造对数据」**；「配置正确」≠「行为正确」；「部署 EXIT=0」≠「函数能起」（语法错→整函数 502）。
- **同一事实 3–5 处副本**，改一节要全仓扫；grep 按编码（AOT 中文 UTF-16LE，ASCII 字面量明文）；字段名按「定义方 + 使用方」两处核实。
